# Foncig.Host

Platform shims for `Foncig` on .NET, Fable JavaScript (Node, Bun, Deno) and Fable Python:
`Host.env`, `Host.args`, `Host.tryReadFile` (UTF-8, BOM stripped), `Host.homeDir`, `Host.cwd`, `Host.pathJoin`,
`Host.expandHome`, `Host.searchUpward`, and `HostSources.file` (format chosen by extension, optional or required).
Public signatures use plain F# types only.
